1. 在 GitHub 建空仓库 `dissipation-locator`（不要勾选自动生成 README），本地 push：

```bash
cd dissipation-locator
git commit -m "dissipation locator: three-channel dissipation probe + measured runs"
git branch -M main
git remote add origin https://github.com/JTE-V/dissipation-locator.git
git push -u origin main
```

首次提交前先配好 `user.name` / `user.email`。仓库已 `git init` 并 `git add` 完毕，截图占位图已被 `.gitignore` 排除。
